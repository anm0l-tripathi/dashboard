# dashboard
Sales Data Analysis: Cleaning, EDA and Dashboard
End-to-end analysis of a messy 2025 sales dataset (212 raw rows): data cleaning, exploratory analysis, and an interactive dashboard.
Project structure
messy_sales_data.csv      raw data (add your original file here)
task1_clean.py            Task 1: cleaning script
cleaned_data.csv          cleaned dataset (200 rows)
task2_analysis.py         Task 2: statistics and charts
stats_summary.csv         summary statistics
charts/                   9 EDA charts
task3_dashboard_image.py  Task 3: builds the dashboard image and PDF
sales_dashboard.html      interactive dashboard (open in a browser)
dashboard_preview.png     dashboard image
dashboard.pdf             dashboard as PDF
powerbi_data.csv          data prepared for Power BI
POWERBI_GUIDE.md          steps to build the Power BI version
sales_dashboard.pbix      Power BI file (add after building it)
